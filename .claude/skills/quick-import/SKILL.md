# 制衣厂一键录入技能

## 工作流程

当用户要求录入数据时，按以下步骤执行：

### 第1步：解析用户输入

从用户的口语描述中提取以下信息：

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| styleNo | ✅ | 款号 | "TX-001" |
| styleName | ❌ | 款式名称 | "夏季T恤" |
| bedNo | ✅ | 床号 | "1号床" |
| bedName | ❌ | 床号名称，默认"大货" | "大货" |
| colors | ❌ | 颜色 | "黑色" |
| processes | ❌ | 工序列表 | [{"name":"裁剪","price":0.5}] |
| bundles | ✅ | 扎货列表 | [{"quantity":50,"size":"M"}] |

### 第2步：检查必填字段

如果缺少以下字段，必须询问用户：
- **styleNo**（款号）
- **bedNo**（床号）
- **bundles**（至少一扎，包含 quantity）

询问示例：
```
你还没告诉我款号是什么？请提供款号。
```

### 第3步：整理数据

将提取的信息整理成JSON格式：

```json
{
  "styleNo": "TX-001",
  "styleName": "夏季T恤",
  "bedNo": "1号床",
  "bedName": "大货",
  "colors": "黑色",
  "bundles": [
    { "quantity": 50, "size": "M" },
    { "quantity": 50, "size": "L" }
  ]
}
```

### 第4步：展示确认

将整理好的数据展示给用户，格式如下：

```
我帮你整理好了录入数据：

款号：TX-001（夏季T恤）
床号：1号床（大货）
颜色：黑色
扎货：
  - A001: 50件, M码
  - A002: 50件, L码

共 2 扎，100 件

确认录入吗？
```

### 第5步：调用API

用户确认后，调用API：

```bash
curl -X POST "http://localhost:8080/api/quick-import" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {token}" \
  -H "X-Company-Id: {companyId}" \
  -d '{"styleNo":"TX-001","bedNo":"1号床","bundles":[{"quantity":50,"size":"M"},{"quantity":50,"size":"L"}]}'
```

## 常见用户表达方式

用户可能会这样说：

- "在TX-001下录一个1号床，50件M码，50件L码"
- "帮我录入，款号是TX-001，1号床，分两扎，各50件"
- "TX-001款，1号床，100件，分2扎"
- "录一下，TX-001，1号床，M码50件，L码50件，XL码30件"

## 注意事项

1. **款号和床号不存在会自动创建**，所以不需要确认是否存在
2. **扎号会自动生成**（A001、A002...），用户不需要指定
3. 如果用户只说总件数和扎数，需要自动计算每扎件数
4. 如果用户没说尺码，可以不填（size字段可选）
5. 工序信息可选，如果用户提到了才添加

## 示例对话

**用户**: 帮我录入一下，TX-001款，1号床，100件分2扎

**助手**: 
好的，我帮你整理一下：

款号：TX-001
床号：1号床
扎货：
  - 50件（尺码未指定）
  - 50件（尺码未指定）

共 2 扎，100 件

请问：
1. 需要指定尺码吗？
2. 这些数据确认录入吗？

**用户**: 尺码都是M，确认录入

**助手**:
```json
{
  "styleNo": "TX-001",
  "bedNo": "1号床",
  "bundles": [
    { "quantity": 50, "size": "M" },
    { "quantity": 50, "size": "M" }
  ]
}
```

正在调用API录入...

录入成功！
- 款号：TX-001（新建）
- 床号：1号床（新建）
- 扎货：A001（50件M码）、A002（50件M码）
