# 床号工序编辑设计

## 目标

老板在生产管理页面的床号卡片上可以进入工序编辑。单价为 0 的工序允许修改名称、单价、顺序或删除；单价大于 0 的工序保持锁定。

## 方案

复用 `PUT /api/bed/{id}` 和后端现有锁定校验。在 `Bundle.vue` 墠加“编辑工序”按钮与工序编辑弹窗，提交时仅发送当前床号必要字段和完整工序列表。保存成功后重新请求床号列表，确保工序 ID、锁定状态和显示数据以服务端为准。

## 交互

- 床号卡片底部显示“编辑工序”按钮。
- 弹窗按顺序展示名称和单价。
- 单价为 0 的工序可编辑、移动和删除。
- 单价大于 0 或 `priceLocked` 的工序禁用编辑，并显示锁定状态。
- 可新增工序，新工序单价默认为 0。
- 保存失败时展示服务端错误，不关闭弹窗。

## 验证

- 回归测试确认入口、编辑控件、锁定条件和 `updateBed` 调用存在。
- 运行全部前端测试和生产构建。
