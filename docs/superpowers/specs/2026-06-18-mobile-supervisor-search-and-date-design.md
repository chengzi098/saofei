# 主管手机搜索与移动日期选择设计

## 目标

- 主管手机工作看板支持按款号或床号搜索，并可从匹配结果直接打开床号详情。
- 员工记录页和主管审核页不再使用桌面范围日历，改用手机系统原生日期选择。

## 手机看板搜索

- 搜索框提示为“搜索款号或床号”。
- 款号命中时保持原款式卡片行为。
- 床号命中时在款式卡片内展示所有匹配床号。
- 点击匹配床号直接打开该床号底部详情。

## 手机日期选择

- 自定义日期使用两个独立的原生 `<input type="date">`。
- 开始日期和结束日期均占满可用宽度，触控区域不小于 44px。
- 结束日期最小值绑定开始日期；开始日期最大值绑定结束日期。
- 结束日期早于开始日期时自动调整为开始日期。
- 提供今天、最近7天、本周、本月快捷范围。
- 日期完整后自动触发记录刷新。

## 范围

- `MobileSupervisorBoard.vue`
- `MobileRecords.vue`
- `MobileSupervisorReview.vue`
- 新增可复用 `MobileDateRangePicker.vue`
- 不修改后端、数据库或部署文件。
