# 生产管理单页工作台设计

## 目标

将现有分散在“款式管理、分扎管理、打印二维码”三个页面的操作，收敛为一个连续工作台：

`新增款式 → 新增床号 → 分扎 → 打印`

操作过程中始终保留当前款式和床号上下文，不要求用户反复返回列表或重新筛选。

## 页面结构

- 顶部固定显示四步进度：款式、床号、分扎、打印。
- 未选择款式时显示款式卡片列表，可直接新增款式。
- 选择款式后显示该款式的床号卡片，可直接新增床号。
- 选择床号后在同一工作台显示现有分扎编辑区。
- 分扎保存后，点击打印在右侧抽屉中显示当前床号标签，不跳转独立打印页面。
- 面包屑允许返回款式或床号层级，但新增保存后自动进入下一步。
- 选择款式或床号后，在内容区左上方显示高对比度的独立回退按钮。床号层显示“返回款式列表”，分扎层显示“返回床号列表”。

## 导航

- 生产管理侧栏只保留一个“生产管理”入口。
- 工序模板保留原入口和原逻辑，不做修改。
- `/style` 作为新的生产管理主入口。
- `/bundle` 和 `/bundle/print` 保留兼容，避免旧书签失效。

## 数据与权限

- 复用现有款式、床号、分扎、二维码接口，不修改数据库和后端。
- 新增款式后使用接口返回的 ID 直接选中该款式。
- 新增床号后使用接口返回的 ID 直接选中该床号并生成默认分扎行。
- 已打印扎货的禁止编辑规则保持不变。

## 错误处理

- 保存失败时停留在当前层级和当前表单。
- 打印数据加载失败时保留当前床号上下文，仅关闭或重试打印抽屉。
- 新增成功后若详情刷新失败，重新加载当前款式或床号列表。

## 验收标准

1. 用户从生产管理入口可连续完成款式、床号、分扎、打印。
2. 新增款式保存后直接进入该款式床号列表。
3. 新增床号保存后直接进入该床号分扎区。
4. 打印预览在当前页面抽屉打开。
5. 侧栏不再并列展示款式管理、分扎管理和打印二维码。
6. 工序模板页面和功能保持原样。
7. 前端构建与相关测试通过。
